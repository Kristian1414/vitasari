# Folder Gambar

Taruh foto asli Vitasari di sini:

- `hero.jpg`   -> foto besar di halaman beranda (disarankan 1000x1000 px, ditampilkan bulat)
- `about.jpg`  -> foto di halaman Tentang (disarankan 800x1000 px)
- `products/<id-produk>.jpg` -> foto tiap produk (disarankan 800x600 px)

Nama file produk harus sama persis dengan kolom `image` di `src/data/products.js`,
contoh: produk dengan `image: '/images/products/roti-coklat-keju.jpg'`
membutuhkan file `products/roti-coklat-keju.jpg`.

Selama file belum ada, website otomatis menampilkan placeholder bergradasi.
